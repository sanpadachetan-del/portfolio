# Portfolio Website

This is a from-scratch HTML/CSS/JavaScript implementation based on the screenshots you provided.

## Run
1. Open this folder in VS Code.
2. Open `index.html`.
3. Install the VS Code **Live Server** extension if needed.
4. Right-click `index.html` → **Open with Live Server**.

## Edit your details
Search in `index.html` for:
- `Your Name`
- `Your City`
- `your@email.com`
- phone number
- LinkedIn/GitHub links
- education
- experience
- project details

Replace the `YOUR PHOTO` placeholder with an `<img>` if you want your own picture.

This implementation is intentionally written from scratch rather than copying the site's source code.
